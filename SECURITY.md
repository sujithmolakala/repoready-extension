# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in repoready-extension, please report it through a private channel rather than opening a public GitHub issue.

Publicly disclosing vulnerabilities before they are addressed can put users at risk.

Please report security issues privately to **security@repoready.dev**.

Include as much detail as possible so the issue can be reproduced and evaluated. Security reports will be reviewed as promptly as reasonably possible, and reporters may be contacted for additional information.

## Supported Versions

RepoReady is currently under active development. Security updates are provided for the latest released version of the extension.

Older versions may not receive security fixes. Users are encouraged to update to the latest available version before reporting an issue that may already have been addressed.

As the project matures and begins maintaining multiple release lines, this policy may be updated with a formal supported-version table.

## What to Include in a Report

Helpful reports usually include:

- The affected component or area of the project.
- Steps to reproduce the issue.
- The potential impact.
- Any mitigation or workaround you have identified.
