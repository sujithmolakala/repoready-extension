# Contributing to repoready-extension

## Getting Started

repoready-extension is a browser extension that analyzes GitHub repositories, scores repository health, and generates missing open-source documentation using AI.

To set up the project, install the dependencies:

```bash
npm install
```

## Running Tests

To run the test suite and verify your changes:

```bash
npm test
```

## Submitting Changes

Thank you for considering contributing to repoready-extension. When preparing a change, please:

- Focus on a single improvement or fix per pull request.
- Run the relevant tests to ensure your changes do not break existing functionality.
- Provide a clear description of what was changed and why in your pull request.
- Submit your pull request against the default branch once your changes are ready for review.

## Reporting Issues

If you encounter bugs or have questions, please use GitHub Issues to report them.

When reporting an issue, include clear steps to reproduce the problem along with any relevant environment details to help us investigate effectively.
