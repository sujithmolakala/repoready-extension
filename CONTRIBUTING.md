# Contributing to repoready-extension

## Getting Started

repoready-extension is a browser extension that analyzes GitHub repositories, scores repository health, and generates missing open-source documentation using AI.

To get started, install the project dependencies:

```bash
npm install
```

## Running Tests

To run the project test suite, use the following command:

```bash
npm test
```

## Submitting Changes

Thank you for considering contributing to repoready-extension. When preparing a change, please follow these guidelines:

- Keep the scope focused on a single improvement or fix.
- Run the relevant tests before submitting a pull request.
- Provide a clear explanation of what changed and why in the pull request description.
- Open a pull request against the default branch when your change is ready for review.

## Reporting Issues

Please use GitHub Issues to report bugs or ask questions.

When reporting an issue, include clear steps to reproduce the problem along with any relevant environment details.
